# Argo Codes

> *An interactive, MacOS inspired personal portfolio and desktop environment built with Next.js and Tailwind CSS.*

[See for yourself](https://argocodes.vercel.app/)

## Features
- A fully functional Desktop like experience
- Open, close, switch between multiple applications
- A terminal emulator with multiple commands
- Discover all my projects through Finder 
- An IOS like layout on mobile devices (coming soon...)

## Tech stack
- **Framework**: [Next.js 16](https://nextjs.org/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com)
- **Icons**: [Lucide React](https://lucide.dev.)
- **Runtime**: [Bun](https://bun.sh)
- **Programming Language**: [TypeScript](https://www.typescriptlang.org)
